<task type="auto">
  <name>Task 2: Wire into runs, ad-hoc invoices and void</name>
  <files>backend/app/billing.py, backend/app/billing_repo.py</files>
  <action>
_pull_agreements returns the block agreement's 'agreement' line (price unit_price_cents; the existing proration credit line still applies for partial months). In create_run, when that line exists, call _pull_block: included = block_included_minutes(...); candidates = block_candidates(...); covered = allocate_block(...); for every candidate SET block_minutes_covered = covered[id] (overwriting any stale value, 0 when uncovered); entries with covered == minutes_billable get invoice_line_id = block line id; update the block line description to '<name>: N h included, U h used' (money.hours, U = sum of covered). _pull_time then counts each entry as (minutes_billable - block_minutes_covered) minutes and skips entries where that is 0, so the straddling entry links to its overage 'time' line (hourly_rate with org override, work type taxability). If the overage work type has no rate the straddling entry stays unbilled with its covered minutes set and the usual warning. In create_invoice with include_unbilled, exclude entries of block_covered work types whose work_date falls in a calendar month that overlaps any block agreement of that org. In void_invoice, before _release, reset block_minutes_covered = 0 for (a) entries whose invoice_line_id is in the released line ids and (b) unlinked entries (invoice_line_id NULL) of the same org with block_minutes_covered > 0 and work_date within the voided invoice's billing period, then call _release as today. Existing audit records for run and void stay as they are.
