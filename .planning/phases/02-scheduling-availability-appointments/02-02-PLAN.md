<task type="auto">
  <name>Task 1: availability.py</name>
  <files>backend/app/availability.py</files>
  <action>
Module docstring: pure functions, no DB, all datetimes timezone-aware, results in UTC. Type alias Interval = tuple[datetime, datetime]. Import `_at` from app.sla for local->UTC (do not edit sla.py). Functions: (1) `default_weekly(settings) -> dict[int, tuple[int, int]]`: {d: (settings.business_start_minute, settings.business_end_minute) for d in settings.business_days}. (2) `working_windows(start: datetime, end: datetime, tz: ZoneInfo, weekly: Mapping[int, tuple[int, int]], holidays: Mapping[date, tuple[int, int] | None]) -> list[Interval]`: raise ValueError if start/end naive or end <= start; iterate local dates from start.astimezone(tz).date() - 1 day to end.astimezone(tz).date() + 1 day; skip weekdays (0=Monday) not in weekly; if the date is in holidays: None -> skip the day, (o, c) -> hours = (max(h0, o), min(h1, c)), skip if empty; window = (_at(day, h0, tz), _at(day, h1, tz)); clip to [start, end]; drop empty; return sorted and merged (adjacent/overlapping merged). (3) `merge(intervals) -> list[Interval]` sorted union. (4) `subtract(windows, busy) -> list[Interval]`: windows minus the union of busy, sorted, no zero-length pieces. (5) `free_windows(start, end, tz, weekly, holidays, busy) -> list[Interval]` = subtract(working_windows(...), busy). (6) `overlaps(a: Interval, b: Interval) -> bool` half-open [s, e). (7) `conflicts(slot: Interval, working: list[Interval], time_off: Iterable[tuple[int, str, Interval]], appointments: Iterable[tuple[int, Interval]]) -> list[dict]`: 'outside_hours' when the slot is not fully contained in the union of working windows -> {'kind': 'outside_hours'}; each time off (id, status, interval) overlapping the slot -> {'kind': 'time_off' if status == 'approved' else 'time_off_pending', 'time_off_id': id} (callers pass only pending/approved); each appointment overlapping -> {'kind': 'overlap', 'appointment_id': id}; order: outside_hours, time off by start, overlaps by start.

<task type="auto">
  <name>Task 2: Exhaustive DST and property tests</name>
  <files>backend/tests/test_availability.py</files>
  <action>
No new dependencies (hypothesis is not installed). Tests: (a) For every day of 2026 and zones America/Chicago, America/New_York, Europe/London, Australia/Lord_Howe (30-min DST), America/St_Johns, Asia/Kolkata, UTC: a Mon-Sun 09:00-17:00 weekly gives exactly one window per day of exactly 8 h UTC duration whose local start is 09:00. (b) A 00:00-24:00 window on DST change days lasts 23 h / 25 h (Chicago 2026-03-08 and 2026-11-01; London 2026-03-29 and 2026-10-25) and 24 h on other days. (c) A window starting inside the spring-forward gap (Chicago 2026-03-08 02:30) does not raise and has positive length. (d) Holidays: closed day removes the window; shortened (600, 780) intersects with 09:00-17:00 to 10:00-13:00; a holiday on a non-working weekday changes nothing. (e) Property loops over a seeded random.Random(2026) generating 500 cases of random windows and busy intervals: subtract result is sorted, disjoint, inside the windows, disjoint from busy, and total(windows) == total(result) + total(windows intersect busy). (f) conflicts: fully inside -> []; straddling the end of hours -> outside_hours; approved vs pending time off kinds; touching appointments (end == start) do not overlap; overlapping ones are listed by start. (g) Timezone-aware checks: naive datetimes raise ValueError; end <= start raises ValueError.
