src/scheduling/api.ts
- TypeScript types that mirror the backend schemas: Appointment, Conflict, ConflictKind, AvailabilityRow (with time_off_pending), Window, Schedule and StaffUser.
- Fetchers that use api<T>() from src/api.ts:
  - listAppointments({from, to, techId?, ticketId?, withConflicts?})
  - getAppointment(id)
  - createAppointment(body)
  - updateAppointment(id, patch)
  - cancelAppointment(id, reason?)
  - getAvailability({from, to, userIds?})
  - getSchedule(userId)
  - listStaff(): GET /api/users, filtered to active users whose role is admin or tech, sorted by display name
  - getOrgTimezone(): GET /api/settings .timezone
- Query-key helpers in one exported object `schedulingKeys`: all = ["scheduling"], appointments(params), appointment(id), availability(params), schedule(userId), staff(), orgTimezone(). Pages invalidate with schedulingKeys.all or the specific key.

src/scheduling/zone.ts, pure, using @date-fns/tz TZDate:
- toBoardDate(isoUtc, zone): Date. Returns a 'fake local' Date whose local wall-clock fields equal the instant's wall clock in `zone`.
- fromBoardDate(d, zone): string. The inverse, returning ISO UTC with Z.
- zoneDayRange(day: string 'YYYY-MM-DD', zone) -> {from, to}: the UTC instants of local midnight to the next local midnight. This handles 23-hour and 25-hour days.
- zoneWeekRange(anyDay, zone): Monday 00:00 to the next Monday 00:00 local.
- formatInZone(isoUtc, zone, 'HH:mm').

src/scheduling/board.ts, pure:
- toEvents(appointments, zone): RBC events {id, title: `#${ticket_number} ${organization_name}`, start, end, resourceId: tech_id, conflicts, appointment}.
- toResources(staff): [{id, title}].
- backgroundBlocks(availability, zone). Returns shading blocks of kind 'off_hours', 'time_off' or 'time_off_pending' per resource, where off-hours is the complement of the working windows within the visible range.
- dropPatch(appointment, {start, end, resourceId}, zone). Returns the minimal PATCH body, with only the changed fields among tech_id, starts_at and ends_at as ISO UTC. It returns null when nothing changed.
- undoPatch(before, after). Returns the PATCH that restores before's tech_id, starts_at and ends_at.
- conflictLabel(kind). Uses the exact labels from the phase decisions.
- moveSummary(before, after, staff). Returns 'Moved to Sam', 'Rescheduled to Tue 14:00' or 'Resized to 1h 30m', or a combination such as 'Moved to Sam, Tue 14:00'.

Tests in zone.test.ts and board.test.ts:
- America/Chicago round-trips on the spring-forward day (2030-03-10) and the fall-back day (2030-11-03).
- zoneDayRange lengths are 23h and 25h on those days.
- A Australia/Sydney instant viewed in a Chicago board.
- dropPatch: no-op returns null; a tech-only change; a time-only change; a resize changes only ends_at.
- undoPatch inverts dropPatch.
- backgroundBlocks for a day with split working windows and an approved and a pending time off.
- Every conflictLabel.
- moveSummary variants.
