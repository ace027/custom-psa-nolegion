<task type="auto">
  <name>Task 2: Isolated local e2e runner</name>
  <files>scripts/e2e.sh, frontend/vite.config.ts, frontend/playwright.config.ts, docs/DEVELOPMENT.md</files>
  <action>
vite.config.ts: the proxy target becomes `http://localhost:${process.env.E2E_API_PORT ?? 8000}`. Nothing else changes.

playwright.config.ts: add workers: 1 and retries: 0, and keep the existing baseURL and CHROMIUM_PATH handling.

scripts/e2e.sh (bash, set -euo pipefail, executable), usage `scripts/e2e.sh [playwright args/specs...]`:

1. Database name: DB=psa_e2e_$$.
2. Superuser psql:
   - E2E_PSQL if set.
   - Otherwise, when run as root, `runuser -u postgres -- psql`.
   - Otherwise `sudo -u postgres psql`.
3. Create the database owned by psa_owner. If the roles are missing, create them the way .github/workflows/ci.yml and backend/tests/conftest.py expect: psa_owner/owner_dev, and psa_app/app_dev with NOSUPERUSER NOBYPASSRLS.
4. Export, for the API process only:
   - DATABASE_URL=postgresql+psycopg://psa_app:app_dev@localhost:5432/$DB
   - MIGRATION_DATABASE_URL=postgresql+psycopg://psa_owner:owner_dev@localhost:5432/$DB
   - DEV_LOGIN_ENABLED=true
   - ENVIRONMENT=development
   Then run `alembic upgrade head` and `python -m app.seed` in backend/.
5. Pick two free ports with python (bind to port 0).
6. Start the API with `uvicorn app.main:app --port $API_PORT` in backend/.
7. Start the frontend with `E2E_API_PORT=$API_PORT npx vite --port $WEB_PORT --strictPort` in frontend/.
8. Wait up to 60s for both: curl the API health route (find its path in backend/app/routers/health.py) and the Vite root.
9. Run `npx playwright test "$@"` in frontend/ with E2E_BASE_URL=http://localhost:$WEB_PORT. Pass CHROMIUM_PATH through. If it is unset and /opt/pw-browsers/chromium exists, leave it unset: PLAYWRIGHT_BROWSERS_PATH is used.
10. A trap on EXIT kills both processes and drops the database (`DROP DATABASE IF EXISTS`), even on failure.
11. Logs go to a temp dir, and their paths are printed on failure.

In docs/DEVELOPMENT.md, under 'Browser smoke test', document scripts/e2e.sh: what it isolates and an example run.
