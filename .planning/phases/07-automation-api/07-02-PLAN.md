Required interfaces/content structure:
- app/api_keys.py: generate() -> tuple[str, str, str] (token, prefix, sha256 hex); create(ctx, name: str, permissions: list[str], expires_in_days: int = 365) -> tuple[ApiKey, str]; list_keys(ctx) -> list[ApiKey]; revoke(ctx, key_id: int) -> ApiKey; authenticate(db, token: str) -> ApiKey | None; effective_permission(key: ApiKey, permission: str) -> bool
- routes (tag 'api-keys', all require apikey:manage, cookie-only): GET /api/api-keys, POST /api/api-keys -> 201 {key: ApiKeyOut, token: str} (token returned only here), POST /api/api-keys/{id}/revoke -> ApiKeyOut
- ApiKeyOut: id, name, prefix, permissions, owner_id, owner_name, expires_at, revoked_at, last_used_at, created_at, state ('active'|'expired'|'revoked'); never the hash
- Ctx gains api_key_id: int | None = None (default keeps all existing Ctx(...) calls valid)
- context.api_key_id_var: ContextVar[int | None]
Edge/error cases:
- unknown, malformed, revoked, expired key, and key whose owner is deactivated or demoted -> 401 (demoted owner losing the scope -> 403)
- key with ticket:read calling a ticket:write route -> 403 and auth.denied audit
- creating a key with user:manage, apikey:manage, portal:manage, an unknown permission, an empty list, or a permission the admin's role lacks -> 409
- expires_in_days 0 or 731 -> 422 (Field ge=1 le=730)
- revoking an already revoked key -> 409
- an API key calling /api/api-keys (needs apikey:manage, which keys cannot hold) -> 403
- last_used_at not rewritten within 5 minutes

api_keys.py: generate() builds prefix = secrets.token_hex(4), token = f'psa_{prefix}_{secrets.token_urlsafe(32)}', hash = sha256(token).hexdigest(). create() validates name (1-100 chars stripped), permissions (dedupe, sorted; non-empty; each in the union of MATRIX values; none in KEY_FORBIDDEN; each has_permission(ctx.user.role)) raising Conflict with a clear message, sets expires_at = now + days, user_id = ctx.user.id, audits 'api_key.created' with detail {prefix, permissions, expires_at} (never the token or hash). revoke() raises NotFound/Conflict(already revoked), sets revoked_at/revoked_by_id, audits 'api_key.revoked'. authenticate(db, token): return None unless token matches ^psa_[0-9a-f]{8}_[A-Za-z0-9_-]{20,}$; look up by key_hash with hmac.compare_digest on the stored hash; None if revoked, expired, or owner inactive; update last_used_at only when null or older than 5 minutes. effective_permission(key, perm) = perm in key.permissions and perm not in KEY_FORBIDDEN and has_permission(key.user.role, perm). deps.py: in _make_dependency, read the Authorization header; if it starts with 'Bearer psa_' use the API-key path: authenticate (None -> audit.record_auth_event('auth.api_key_rejected', detail={'prefix': token[4:12], 'path', 'method'}) and 401 'Invalid API key'); permission None (authenticated()) -> 403 'API keys cannot use this endpoint'; not effective_permission -> auth.denied audit with api_key_id and 403; else set api_key_id_var, yield Ctx(db, user=key.user, scope=Scope.all(), api_key_id=key.id). Any other Authorization value falls through to the cookie path unchanged.
