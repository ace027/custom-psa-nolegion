Required interfaces/content structure:

- app/webhooks.py: enqueue(ctx, event_type, event_id, body: dict, endpoint_ids: list[int] | None = None) -> int; check_url(url: str) -> str (raises Conflict); resolve_public(host: str) -> None (raises VendorError-like WebhookBlocked); sign(secret, timestamp: int, raw: bytes) -> str; render(endpoint, body) -> bytes; deliver_due(db, now=None, transport=None, limit=50) -> dict; BACKOFF = (60, 300, 1800, 7200, 21600); MAX_ATTEMPTS = 6
- routes (tag 'webhooks', require automation:manage): GET /api/webhooks, POST /api/webhooks (201, returns {endpoint, secret}), PATCH /api/webhooks/{id}, POST /api/webhooks/{id}/rotate-secret ({endpoint, secret}), POST /api/webhooks/{id}/test (enqueue ping, 202), GET /api/webhooks/{id}/deliveries?status=&limit=, POST /api/webhooks/deliveries/{id}/retry
- WebhookOut: id, name, kind, url_host, url_preview, events, enabled, consecutive_failures, last_success_at, last_failure_at, created_at (never url or secret)
- config: webhook_allow_private_hosts: bool = False (env WEBHOOK_ALLOW_PRIVATE_HOSTS)
Edge/error cases:
- http:// URL, userinfo, fragment, IP literal 10.0.0.1/127.0.0.1/169.254.169.254/::1, hostname resolving to a private address -> 409 at save and failed attempt at send
- DNS failure at send -> retry with error 'DNS lookup failed'
- 3xx, 4xx, 5xx, timeout, connection error -> retry per BACKOFF; 6th failure -> status failed
- disabled endpoint: nothing enqueued; existing pending rows are skipped (left pending) while disabled
- endpoint subscribed to some events only receives those
- retry of a delivered row -> 409; retry of failed row -> pending with attempts 0
- teams kind body is an Adaptive Card message with title, facts and an Open ticket button
- bulk_update of 3 tickets emits per ticket
- rmm alert opened emits rmm_alert.opened after ticket.created; clear emits rmm_alert.cleared
