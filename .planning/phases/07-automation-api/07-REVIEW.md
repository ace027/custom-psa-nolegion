## Deferred (Medium Confidence)
- `backend/app/webhooks.py` [major, 75%]: `deliver_due` sends up to 50 deliveries one after another, each with a 10 s timeout, and `webhook_jobs` runs inline in the worker's single loop. Only about 40 s of the loop's delay is the poll interval, so a few dead or slow endpoints can hold the loop for minutes (50 x 10 s worst case). The same loop also does mail ingest, billing and RMM alert polling. `consecutive_failures` is incremented but never acted on. A permanently failing endpoint keeps getting new deliveries enqueued, and each one burns 6 attempts.
- `backend/app/webhooks.py` [major, 65%]: `_attempt` catches only `Conflict`, `CredentialsKeyError`, `httpx.TimeoutException` and `httpx.HTTPError`. Other exceptions escape: `KeyError` from `_teams_card` (`t["number"]`, `t["url"]`, `alert['severity']`) on a payload that lacks those keys, `httpx.InvalidURL` (it is not an `HTTPError` subclass), `UnicodeError` from IDNA hosts, and a missing `"secret"` key after decrypt. `deliver_due` has no per-row try/except, so the exception aborts the whole batch. The row is rolled back and stays `pending` with the same `next_attempt_at`.
- `frontend/src/pages/Automation.tsx` [minor, 70%]: The Save button stays disabled until the form is valid (name, at least one action, every action and condition complete). Nothing tells the user which requirement is unmet. The Name input has no `required`, unlike the other two pages.
- `frontend/src/pages/Automation.tsx` [minor, 65%]: Clicking Edit on a rule loads it into the form at the bottom of the page. The page does not scroll or move focus there, and the rule being edited is not highlighted in the list. If the user has unsaved edits in the draft, clicking Edit on another rule silently overwrites them.
- `frontend/src/pages/Automation.tsx` [major, 75%]: The multi-value condition uses a native `<select multiple>` with no instruction. Selecting several options requires Ctrl/Cmd-click, and keyboard selection requires Shift or Ctrl with the arrow keys. There is no visible hint, and the select has no size or height styling.

It does not verify that the delivery belongs to an endpoint that is still enabled.
