Edge/error cases:
- worked example from 08-CONTEXT gives 600.00, then 300.00 + 100.00 capped, then a $0 over-budget line; totals exact
- budget lowered below billed_so_far -> remaining 0, all new time on the $0 over-budget line
- taxable work type on a capped line: tax computed on the capped amount via line_amounts
- draft project: neither fee nor time billed; cancelled before approval: nothing billed
- fixed fee approved mid-month: fee on the next run; bill-fixed-fee twice -> 409 'The fixed fee is already billed'
- voiding the invoice with the fee clears fixed_fee_invoice_line_id and releases project time; re-run bills them again
- fixed-fee project time -> one $0 'covered by the fixed fee' line per run, entries linked
- work type without a rate: entries left unbilled with the existing warning
- client with a block agreement: project time does not reduce block minutes
- expenses and product charges on project tickets bill normally and are not counted in the cap
- one-off create_invoice(include_unbilled=True) never pulls project time
