- clientScope.ts: export function clientApiPath(orgId: number, ...parts: (string|number)[]): string -> '/organizations/<id>[/parts]'; export function clientRoute(orgId: number, ...parts): string for UI links; export ClientScopeProvider + useClientScope(): { orgId: number | null; apiPath(...parts): string } where orgId comes from the provider (null today; a global switcher sets it later) falling back to the :id route param on client pages
- api.ts: Organization/Site/Contact types gain uuid: string (Organization also rmm_client_id: string | null); Note gains author_type: 'human' | 'system' | 'ai'; Ticket gains external_ref: string | null and source union 'manual'|'email'|'portal'|'rmm'|'api'|'rule'; asset types gain source and external_id; time entry type gains entry_type: 'labour' | 'automation'; utilisation row gains automation_minutes: number; user type gains entra_tenant_id: string | null
Edge/error cases:
- VITE_BRAND_COLORS invalid JSON: ignored with a console warning, defaults kept
- Logo URL set: an <img alt={BRAND.name}> replaces the text mark
- Notes list with only system notes and the Human filter: an empty-state line 'No human notes'
- Filter buttons are keyboard reachable with aria-pressed
