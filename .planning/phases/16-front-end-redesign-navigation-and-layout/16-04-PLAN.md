<task type="auto">
  <name>Task 1: Palette component</name>
  <files>frontend/src/nav/CommandPalette.tsx</files>
  <action>
Modal dialog (role=dialog, aria-modal, labelled) with a combobox input (aria-activedescendant) and a listbox of results: pages and tabs from navConfig the user can() open, matched on label and keywords; 'Go to ticket #N' when the query is a number (uses the existing ticket-number lookup in api.ts; shows 'Ticket #N not found' on 404); quick actions New ticket, Start a timer, Book an appointment, New quote (each only if the user has the permission its page needs) and Record a payment (payment:write); 'Search tickets for <query>' (existing /search route). With nothing typed it shows Bookmarked, Recent (last 4 pages visited, kept in sessionStorage, excluding bookmarked ones) and Actions. Alt+P on a highlighted page toggles its bookmark through useBookmarks and announces it. Key hints linked with aria-describedby. Arrow keys, Enter, Escape; focus trapped while open and returned to the opener on close. No new dependency; no Knowledge base action.
